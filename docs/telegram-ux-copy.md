# FlatPulse Telegram UX Copy

Актуально для dev-версии. Секретов, токенов и env-значений здесь нет.

Плейсхолдеры:
- `{found}` - количество найденных квартир.
- `{price}` - цена подписки из `SUBSCRIPTION_PRICE_RUB`.
- `{trial_days}` - длительность пробного периода из `TRIAL_DAYS`.
- `{paid_until}` - дата окончания оплаченного доступа.
- `{count}` - количество квартир/записей.
- `{seconds}` - оставшееся время в секундах.
- `{timestamp}` - дата/время.
- `{error}` - текст ошибки.
- `{url}` - ссылка.

## Reply-Кнопки

Первый вход:
- `🔍 Настроить поиск`

- `Начать`
- `🔍 Настроить поиск`
- `Найти квартиру`
- `Меню` — только для старой reply-кнопки, чтобы убрать ее и открыть меню

## Первичная Выдача

Альтернативный текст первичной выдачи:

```text
✅ Поиск настроен.

Я нашел и запомнил текущие объявления: {found}.

Можете посмотреть самые свежие варианты сейчас или вернуться к ним позже в архиве.
```

Перед отправкой квартир:

```text
Показываю квартир: {count}
```

Если квартир нет:

```text
📦 Архив пока пуст.

Сначала настройте поиск и запустите первую проверку. После этого найденные квартиры появятся здесь.
```

Или, если первая проверка уже была:

```text
📦 В архиве пока нет квартир.

По текущим фильтрам ничего не найдено. Попробуйте расширить бюджет, комнаты или область поиска.
```

Если токен бота не задан:

```text
TELEGRAM_BOT_TOKEN не задан.
```

## Trial Offer

Показывается после первичного просмотра квартир или после `Посмотреть позже`.

Сообщение:

```text
Хотите получать новые квартиры раньше других?

FlatPulse будет проверять ЦИАН каждые 10 минут и присылать только свежие объявления по вашим фильтрам.

Попробуйте сейчас за 0 ₽ на {trial_days} дней. После пробного периода — {price} ₽ в месяц.

Без автосписаний: следующий месяц оплачивается вручную.
```

Кнопки:
- `Попробовать {trial_days} дней бесплатно`
- `Не сейчас`

Если пользователь запускает trial:

```text
✅ Бесплатный период запущен.

{trial_days} дней я буду проверять новые квартиры и присылать только свежие варианты по вашим фильтрам.
```

Если trial уже активен:

```text
✅ Бесплатный период уже активен.

Он действует до {trial_ends_at}. Новые квартиры будут приходить автоматически.
```

Если trial уже был использован:

```text
Бесплатный период уже был использован.

Чтобы продолжить получать новые квартиры, оплатите следующий месяц вручную: {price} ₽.

Без автосписаний.
```

Если пользователь отказался:

```text
Ок, бесплатный период не запускаю.

Новые квартиры приходить не будут, но найденные варианты можно посмотреть в архиве.
```

## Архив Квартир

Кнопка в главном меню:
- `📦 Архив квартир`

Поведение:
- отправляет до 10 сохраненных квартир по текущему поиску;
- если сохраненных квартир нет, показывает:

```text
По текущим фильтрам пока ничего не найдено.
```

## Управление Поиском

Остановка:

```text
Поиск остановлен. Новые объявления по нему больше не будут приходить.
```

Возобновление при активном доступе:

```text
Поиск возобновлен. Первый запуск запомнит текущие объявления, а дальше будут приходить только новые.
```

Возобновление без trial/paid:
- показывает `Trial Offer`.

Удаление:

```text
Поиск удален. Чтобы начать заново, настройте параметры поиска.
```
